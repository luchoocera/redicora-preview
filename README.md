# Preview de REDICORA

Presentación académica del estudio de diseño industrial REDICORA y sus proyectos. Este repositorio contiene una versión compilada para GitHub Pages.

La web está en `site/`. El código de desarrollo se mantiene en un repositorio privado separado.

## Publicación manual

En Settings → Pages, seleccionar GitHub Actions como origen. Después, en Actions → Publicar preview REDICORA → Run workflow, seleccionar main y ejecutar la publicación.

El flujo solo responde a la ejecución manual. Subir nuevos archivos no lo ejecuta automáticamente. El paquete que se publica contiene exclusivamente `site/`.

La dirección prevista después de publicar es https://luchoocera.github.io/redicora-preview/.

## Recursos

Esta versión incluye el visor 3D de la lámpara telescópica de Despliegue compacto. Los archivos servidos por la web, incluido el GLB, son públicos y descargables.

Las fuentes y bibliotecas conservan sus avisos y licencias en `site/assets/fonts/` y `site/assets/licenses/`. Esas licencias corresponden a dichos recursos; no otorgan una licencia general sobre los diseños de productos o la identidad del estudio.
